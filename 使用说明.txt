驱界  v1.0.0
Windows 驱动检测、更新与设备修复工具

============================================================
一、启动
============================================================
双击“驱界.exe”启动。

驱界必须使用管理员权限运行：
  Windows 会弹出 UAC（用户帐户控制）提示，
  请点击“是”，否则驱动安装功能不可用。

打开后会自动扫描本机在线设备，并查询 Windows Update
中的驱动更新。也可以在概览页点击“检查驱动”手动扫描。

============================================================
二、功能页面
============================================================
【概览】
  • 自动扫描本机 PnP 设备
  • 显示缺失驱动、异常设备、过旧驱动和可用更新数量
  • 驱动健康评分
  • 需要关注的设备列表
  • Windows Update 驱动更新预览

【设备驱动】
  • 列出本机在线设备、设备类型、制造商、驱动版本和日期
  • 支持按缺失、异常、过旧、正常筛选
  • 支持搜索设备名称、类型、制造商
  • 点击设备查看问题代码、硬件 ID、实例 ID 和驱动详情

【驱动更新】
  • 通过 Windows Update 查询驱动类别更新
  • 选择后下载并安装
  • 安装完成后自动重新扫描设备
  • 支持打开 Windows 更新可选更新
  • 支持从包含 .inf 的文件夹导入离线驱动

【设置】
  • 深色 / 浅色 / 跟随系统
  • 打开应用时自动扫描
  • 过旧驱动年限阈值
  • 数据目录、日志、设备管理器入口

============================================================
三、驱动来源说明
============================================================
在线驱动更新来自 Windows Update 的驱动类别，
只包含微软认证并分发的驱动包。

它不是厂商驱动商店：
  • NVIDIA / AMD / Intel 显卡驱动
  • 部分网卡、声卡、蓝牙驱动
  如果这些驱动没有通过 Windows Update 发布，
  需要从厂商官网下载，或使用厂商工具安装。

如果 Windows Update 没有找到缺失设备的驱动：
  1. 打开“驱动更新”页；
  2. 点击“打开 Windows 更新”查看可选更新；
  3. 或从厂商官网下载包含 .inf 的驱动包；
  4. 再点击“从文件夹安装驱动”。

============================================================
四、安装驱动前的建议
============================================================
• 保存正在处理的工作
• 安装驱动期间不要强制关机
• 部分驱动需要重启电脑后生效
• 建议在重大驱动更新前创建系统还原点
• 不要安装来源不明的 .inf 驱动包

============================================================
五、运行环境
============================================================
• Windows 10 / 11 64 位
• Microsoft Edge WebView2 运行时
• .NET 10 Desktop Runtime

数据目录：
  %LOCALAPPDATA%\QuJie
包括设置、日志和 WebView2 缓存，不包含驱动安装包。

============================================================
六、卸载
============================================================
驱界是绿色免安装程序：
  1. 退出驱界；
  2. 删除整个“驱界”文件夹；
  3. 如需清除设置和日志，再删除 %LOCALAPPDATA%\QuJie。

驱动本身已经安装到 Windows 驱动库中，
删除驱界不会卸载已经安装的驱动。
